# Route / facility hero backgrounds

Place **2** wide photos:

- `court-a.webp`
- `court-b.webp`

Used by `.route-card--court-a` / `.route-card--court-b` (see `src/styles/tennis-overrides.css` for gradient fallbacks until files exist).

Then set `USE_MEDIA_PLACEHOLDER` to `false` in `src/config/tennis-assets.ts`.
