# Logo & brand marks

Expected filenames (see `src/config/tennis-assets.ts`):

| File | Usage |
|------|--------|
| `favicon.png` | Site favicon (512×512) |
| `brand-mark-default.png` | Header logo, default state |
| `brand-mark-hover.png` | Header logo, hover state |
| `horizontal-white.png` | Footer / OG / brand strip logos |
| `partner-placeholder.png` | Partner slot (replace with sponsor) |

Until these exist, the UI uses `public/assets/images/_placeholder.svg` when `USE_MEDIA_PLACEHOLDER` is `true`.
